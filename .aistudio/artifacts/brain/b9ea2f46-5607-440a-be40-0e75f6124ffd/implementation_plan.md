# خطة التطوير الشامل لتطبيق إبرة وخيط: إدارة الموديلات، جودة الخط العربي، والتخزين الدائم والنسخ الاحتياطي

تهدف هذه الخطة إلى نقل تطبيق **إبرة وخيط** إلى مستوى التطبيقات التجارية المتكاملة دون المساس بالهوية البصرية الأنيقة أو الحسابات المالية الدقيقة.

---

## مراجعة القرارات الحاسمة (User Review & Critical Decisions)

> [!IMPORTANT]
> 1. **توسيع وظيفة تعديل الموديل**: بناء شاشة تعديل متكاملة (`EditProductScreen`) تتيح تعديل الاسم، الصورة الرئيسية، تكلفة القطعة، سعر البيع المقترح، إدارة الألوان (إضافة/تعديل/حذف)، وإدارة القياسات وكمياتها لكل لون باستقلالية تامة، مع تسجيل أي تعديل كمي كحركة تعديل مخزني، دون المساس بتكاليف الدفعات السابقة (FIFO) أو فواتير المبيعات الصادرة.
> 2. **إصلاح عرض اللغة العربية جذرياً**: تثبيت خط **Cairo** العربي المتصل والمصمم للأجهزة الذكية محلياً في مجلد `res/font/` باستخدام أداة `font-util`، وتحديث `Type.kt` وضبط `letterSpacing = 0.sp` و`lineHeight` المرن لتفادي تداخل الحروف أو تشوه الكلمات في الشريط السفلي وبطاقات الإحصائيات.
> 3. **التخزين المحلي الدائم عبر Room Database**: تحويل جميع الكيانات (الموديلات، الألوان، القياسات، دفعات الشراء، فواتير المبيعات، تفاصيل الأصناف المباعة، المصاريف، حركات المخزون) إلى جداول SQLite عبر Room مع المعاملات الذرية (`@Transaction`) والتدفق التفاعلي (`Flow`).
> 4. **حفظ الصور الدائم**: تخزين الصور المختارة من قِبل المستخدم محلياً داخل مجلد الملفات الداخلية للتطبيق (`filesDir/images/products/` و`filesDir/images/colors/`) وربط مساراتها المحلية الدائمة بقاعدة البيانات.
> 5. **قسم النسخ الاحتياطي والاستعادة (ZIP)**: إنشاء شاشة إعدادات تضم وظيفة تصدير نسخة احتياطية بصيغة ZIP تحتوي على نسخة قاعدة البيانات `database.sqlite`، ملفات JSON الوصفية، مجلد الصور، وشهادة التحقق SHA-256، عبر Android Storage Access Framework (SAF). وعند الاستيراد، يتم فحص الملف وإنشاء نسخة وقائية تلقائية لضمان عدم فقدان البيانات في حال فشل الاستيراد.
> 6. **تكبير ودجت السلة بنسبة 200%**: مضاعفة حجم زر/ودجت السلة العائم في قسم المبيعات ليكون زراً بيضاوياً عريضاً وبارزاً (Extended FAB) يعرض بوضوح عدد القطع الإجمالي وقيمة السلة بالدينار العراقي (IQD).

## 2. تفصيل التعديلات الثلاثة الرئيسية

### التعديل الأول: تطوير وظيفة تعديل الموديل الشاملة (`EditProductScreen`)

- **الواجهة**: صفحة طولية انسيابية مخصصة للتعديل مقسمة إلى بطاقات واضحة:
  1. **البيانات الأساسية**: تعديل اسم الموديل، تغيير الصورة عبر Photo Picker وحفظها محلياً، تعديل التكلفة الافتراضية، وتعديل سعر البيع المقترح.
  2. **قسم الألوان**:
     - عرض قائمة الألوان الحالية للموديل مع صورها.
     - زر `+ إضافة لون جديد`.
     - إمكانية تعديل اسم اللون أو استبدال صورته.
     - زر حذف اللون (مع فحص أمان: إذا كان للون مبيعات أو دفعات شراء مسجلة، يتم وضعه في حالة "أرشفة/غير نشط" لمنع بيعه مستقبلاً مع الحفاظ على سجلاته التاريخية).
  3. **قسم القياسات والكميات لكل لون**:
     - استعراض قياسات كل لون على حدة.
     - إضافة مقاس جديد للون محدد.
     - تعديل كمية المخزون لأي مقاس مع توثيق الفارق في جدول `stock_movements` (حركة تعديل جردي).
     - حذف المقاس غير المستعمل.
- **الحماية المحاسبية**:
  - الحسابات تعتمد على التكلفة المخزنة في الدفعات (`purchase_batches`). تعديل تكلفة الموديل الافتراضية يؤثر فقط على الدفعات المستقبلية.
  - الفواتير السابقة تحتفظ بأسعار وتكاليف البيع التاريخية دون أي تغيير.

### التعديل الثاني: إصلاح الخطوط واللغة العربية

1. **الخط العربي الرسمي**:
   - تثبيت وتضمين خط **Cairo** (أوزان Regular, Medium, Bold) محلياً داخل `app/src/main/res/font/cairo.ttf`.
   - ربط الخط في `Type.kt` على كامل عناصر `MaterialTheme.typography` (العناوين، النصوص، الأزرار، التسميات).
   - ضبط `letterSpacing = 0.sp` لمنع تقطع الحروف العربية، وضبط `lineHeight` بما يتناسب مع خطوط النسخ والرقعة الهندسية.
2. **شريط التنقل السفلي**:
   - موازنة ارتفاع شريط التنقل وحجم الأيقونات (20dp) وحجم الخط (10.5sp)، مع تقييد عدد الأسطر بحد أقصى سطر واحد دون اقتصاص.
3. **بطاقات الإحصائيات**:
   - استخدام تصميم شبكي مرن يتكيف مع الشاشات الصغيرة والمتوسطة والكبيرة، مع عرض أرقام الدينار العراقي (IQD) بخط عريض وواضح دون تداخل.

### التعديل الثالث: التخزين الدائم (Room) والنسخ الاحتياطي (ZIP)

1. **كيانات Room Database**:
   - `ProductEntity`: id, name, mainImagePath, defaultCostIqd, defaultSellIqd, isArchived, createdAt.
   - `ColorVariantEntity`: colorId, productId, colorName, colorImagePath, isArchived.
   - `SizeStockEntity`: sizeId, colorId, productId, sizeLabel, currentStock, isArchived.
   - `PurchaseBatchEntity`: batchId, productId, colorId, sizeLabel, purchasedQty, remainingQty, unitCostIqd, purchaseDate, timestamp.
   - `SaleInvoiceEntity`: invoiceNumber, saleDateTime, totalAmountIqd, cogsTotalIqd, grossProfitIqd, customerName, customerPhone, timestamp.
   - `SoldItemDetailEntity`: itemId, invoiceNumber, productId, productName, colorName, sizeLabel, quantity, unitSellingPriceIqd, totalPriceIqd, cogsIqd.
   - `ExpenseEntity`: id, title, category, amountIqd, date, notes.
   - `StockMovementEntity`: movementId, productId, colorId, sizeLabel, movementType (PURCHASE, SALE, ADJUSTMENT), quantityChange, reason, timestamp.
2. **إدارة الصور الدائمة**:
   - عند اختيار صورة للموديل أو اللون، يتم نسخها فوراً إلى `context.filesDir/images/` وتخزين المسار المحلي الدائم في قاعدة البيانات لضمان بقائها بعد إعادة تشغيل الجهاز.
3. **النسخ الاحتياطي بصيغة ZIP**:
   - **التصدير**: ضغط ملف قاعدة البيانات `database.sqlite` ومجلد الصور `images/` وملف الفهرس `backup_info.json` (الذي يحتوي على تاريخ النسخة، عدد المنتجات، الفواتير، وحساب SHA-256) وتصدير الملف بصيغة `EbraWaKhait_Backup_yyyy-MM-dd.zip` عبر Android SAF (`CreateDocument`).
   - **الاستيراد**: اختيار ملف ZIP عبر SAF (`OpenDocument`)، التحقق من سلامة البنية ومطابقة الملفات، عمل نسخة احتياطية وقائية فورية من البيانات الحالية، ثم استخراج وتحديث قاعدة البيانات والصور بشكل ذري، مع إمكانية التراجع في حال حدوث أي خطأ.
   - **التذكير بالنسخ**: إشعار المستخدم بتاريخ آخر نسخة احتياطية وتنبيهه إذا مضى أكثر من أسبوعين دون إنشاء نسخة جديدة.

### التعديل الرابع: تكبير ودجت السلة بنسبة 200%

- تحويل ودجت السلة العائم في قسم المبيعات إلى ودجت بارز عريض (Extended FAB) بأبعاد مضاعفة:
  - حجم أكبر وأوضح مع أيقونة السلة (بحجم 36dp).
  - شارة عدد القطع بخط كبير واضح.
  - نص يوضح إجمالي مبلغ السلة الحالي بالدينار العراقي (IQD).

## 3. خطة التنفيذ خطوة بخطوة

1. **الخطوط**: تنزيل خط Cairo عبر `font-util install "Cairo" --target app/src/main/res/font`، وتحديث `Type.kt` وضبط قياسات النصوص ومسافات الأسطر.
2. **قاعدة البيانات**: إنشاء كيانات Room الـ 8، الـ DAOs، والـ `AppDatabase`، مع تفعيل المعاملات الذرية ونظام الترحيل.
3. **حفظ الصور محلياً**: كتابة مساعد `ImageStorageManager` لنسخ وحفظ واسترجاع صور المنتجات محلياً.
4. **المستودع (StoreRepository)**: ربط الـ ViewModel بقاعدة بيانات Room لتوفير تدفقات `Flow` لحظية لكل الشاشات.
5. **شاشة تعديل الموديل (`EditProductScreen`)**: برمجة شاشة تعديل الموديل بكافة أقسامها وحماية الدفعات المالية.
6. **مدير النسخ الاحتياطي (`BackupRestoreManager`)**: برمجة ضغط وفك ملفات الـ ZIP مع فحص الـ Checksum وحفظ الصور والبيانات واستعادتها بأمان.
7. **شاشة الإعدادات والنسخ الاحتياطي (`SettingsScreen`)**: واجهة تصدير واستيراد النسخ الاحتياطية وعرض سجل النسخ وتاريخها.
8. **تكبير ودجت السلة**: مضاعفة حجم زر السلة العائم في شاشة المبيعات وشريط التطبيق.
9. **الاختبار والتجميع**: التحقق من بناء التطبيق بنجاح عبر `compile_applet` وتشغيل سيناريوهات الاختبار الآلية.
